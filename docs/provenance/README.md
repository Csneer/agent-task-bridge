# 迁移来源

本项目的核心/蓝图/协议和测试设计最初在 p-drive 工作区的 `.omx/` 下形成，作为独立新项目的临时规划材料。2026-10-30 迁移到本项目；原文件保留，没有作为 p-drive 产品代码引入。

[migration.json](migration.json) 记录 13 个源文件的原始 SHA-256 与目标路径。source 路径相对于来源项目 `.omx/`，只用于追溯，不是新仓库运行时依赖。新项目内的链接已改为相对路径。

迁移后有以下显式差异：

- 协议版本由 `bridge-m1-draft-1` 更新为 `bridge-m1-1`，Schema identity、capabilities、两个检查器和固定摘要同步更新。
- 当前文档状态更新为实施基线，历史审查保留原时点结论；旧 v9 未迁入实施输入。
- 明确“单次拒绝不证明同键其他未知/在途副本结束”，并在 V17 增加时序；V23 区分自然到期与显式停用的结束原因。
- 修正校验器对合法 IPvFuture 大写 V 的处理，新增两条 URI 正例；原始 URI 字节和摘要不被归一化。
- 新增方法映射、冻结清单、隔离依赖说明、整体校验器、版本规则和实现任务单。

当前文件的精确字节以 [冻结清单](../../protocol/m1/manifest.json) 与 Git 提交为准。源摘要不声称迁移后的文件逐字相同；本清单也不把旧审查结果提升为运行验收。
