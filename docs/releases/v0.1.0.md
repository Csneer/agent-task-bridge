# Agent↔Task Bridge v0.1.0 — Developer Preview

首个可安装的 Agent↔Task 任务桥接参考实现。独立客户端通过统一协议发布、领取和交付任务，指定主体验收，上层通过快照与事件恢复事实。产品标签为 `v0.1.0`，协议保持 `bridge-m1-1`；此版本标记为 GitHub prerelease。

## 包含什么

- Linux Go daemon，HTTP/JSON-RPC、SQLite/WAL、27 个公共方法。
- 原子单一承接、租约与 fencing、状态/交付/验收、原键幂等恢复、快照与 cursor 历史重放。
- 独立 Go CLI、TypeScript SDK/CLI、只读消费者和真实 Agent 交接示例。
- `bridge init` 生成私有新 authority，默认凭据/binding 有效期 30 天；一个无需 npm 依赖的最小示例完成真实计算、提交、Owner 验收与 Reader 历史读取。
- 固定字段请求日志、维护失败观测和进程累计计数，可选择 JSON 日志。

## 安装

从 [v0.1.0 发行页](https://github.com/Csneer/agent-task-bridge/releases/tag/v0.1.0) 下载附件，使用 SHA256SUMS 校验后按 [README 快速开始](https://github.com/Csneer/agent-task-bridge/blob/v0.1.0/README.md#安装与最小闭环) 初始化和启动。

| 附件 | 内容 |
|---|---|
| `agent-task-bridge_v0.1.0_linux_amd64.tar.gz` | amd64 daemon、Go CLI、文档、冻结协议与最小示例 |
| `agent-task-bridge_v0.1.0_linux_arm64.tar.gz` | arm64 交叉编译制品，同样附带文档与示例 |
| `agent-task-bridge_v0.1.0_protocol-m1.tar.gz` | 冻结协议、Schema、方法目录和说明 |
| `csneer-agent-task-bridge-0.1.0.tgz` | 可用 npm install 安装的编译后 TypeScript SDK/CLI |
| `go-dependencies.json` | 去除本机路径的 Go module graph 清单，含 build/test-only 依赖，不是 SBOM |
| `SHA256SUMS` | 附件 SHA-256 校验和 |

二进制包内的 `THIRD_PARTY_LICENSES/` 附带第三方许可证与通知。TypeScript tarball 包含 MIT 许可证、声明文件和冻结 Schema，不依赖源码工作目录。npm registry 发布不属于本次交付。

## 验证与限制

既有 [M1 验收报告](https://github.com/Csneer/agent-task-bridge/blob/v0.1.0/docs/validation/results/README.md) 绑定原始实现提交，覆盖完整状态/授权/租约向量、真实崩溃恢复和独立 H01 交接。本版 CI 在发布前重新执行 Go race/vet/build、TypeScript 与消费者检查、真实 HTTP 集成、冻结摘要检查、独立 npm pack/install 和发行包 smoke；证据附于对应 Actions 运行。初始化与最小 HTTP 闭环由 Go CLI 测试覆盖。

Linux amd64 执行验证；Linux arm64 只交叉编译，尚无 arm64 运行验收。首版仅面向单机/受控私网、预注册主体、单 authority、单 daemon。M1 不清理事件与成功回执；容量需要运维监控。

任务排他性只限制桥内当前授权，不能停止旧进程或保证外部副作用 exactly-once。父子关系不自动授予权限或汇总状态。没有匿名公网市场、多租户、支付/信誉、执行沙箱、push 派单或 Web UI。旧备份回滚、双活、外置密钥原地轮换和通用升级迁移不受支持。部署前阅读 [运维说明](https://github.com/Csneer/agent-task-bridge/blob/v0.1.0/docs/operations.md) 与 [安全策略](https://github.com/Csneer/agent-task-bridge/blob/v0.1.0/SECURITY.md)。
