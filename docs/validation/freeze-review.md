## 冻结审查

三路工作分别负责契约阻断审查、迁移/可移植性核验、实现任务拆分，主代理负责整合。协议审查以当前文件为依据，覆盖 authority、单当前承接、绑定/授权有效性、幂等回执、快照/cursor、提交/决定及历史审计；没有重启核心访谈或增加平台能力。

独立契约审查初次 CONCERNS 提出两项精化，修订后定点复核 **FREEZE_READY**：

1. 明确拒绝只证明本次调用未提交；曾有未知或在途同键副本时继续原键原参数。只有确认没有此类副本的同步确定失败才可改参/换键。V17 已包含超时重试、权限变化、另一副本后续成功的时序。
2. V23 明确自然 binding 到期因 lease 封顶进入 expired/lease_expired；显式停用且 lease 未到期进入 revoked/authorization_revoked。

迁移核验确认 13 个源摘要吻合、目标齐全、无旧仓库运行依赖；两个静态检查器能从项目外 cwd 运行。另修复合法 IPvFuture 大写 V 被 Python URL 解析器拒绝的工具差异，增加 V/v 两个正例，原 URI 不被改写后参与摘要。

## 验证与限制

- 隔离 `.venv` 的 6 个依赖与 requirements-contract.txt 一致，Python 检查通过 **92 个结构样例、7 个摘要样例、9 个解析样例，覆盖 27 方法请求**。
- ECMAScript 独立计算 **7 组 canonical 字节与摘要一致**；版本升级后的摘要已重新计算。
- 整体校验器负责冻结文件 hash/字节数、方法与参数/结果映射、当前文档相对链接，然后运行两个静态检查器。
- 本机 Python 缺少 ensurepip，采用已安装的 uv 将锁定包安装到独立 `.venv`，未修改系统包；README 同时提供标准 venv 和 uv 路径。

可移植性终验结论 **PASS**：从 `/tmp` 使用项目隔离解释器执行整体校验，16 个冻结文件、27 方法映射及 77 个本地链接通过，两个静态检查器通过。源工作区 13 个文件保持原摘要不变。临时副本中的冻结文件改动和清单正文改动均被校验器明确拒绝，临时副本已删除。

实际执行环境为 Python 3.14.4 / Node.js 24.20.0；README 声明的最低支持版本尚未逐一实跑，不能据本机结果宣称所有版本组合已验证。项目验证不依赖当前 cwd、旧工作区或 p-drive 服务。

**not_run：** daemon/SQLite 运行测试、H01/V01–V25、两个完整独立客户端 conformance、真实输入/产物访问和读取方断线恢复。实现任务全部 todo，任何静态结果不得填入运行通过栏。
